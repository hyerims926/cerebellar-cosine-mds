# cerebellar-cosine-mds

Code repository for the study:

**Dissecting the determinants of cerebellar developmental transcriptomic reorganization using in silico perturbation**

This repository contains the code used to analyze developmental transcriptomic reorganization in the mouse cerebellum using cosine dissimilarity-based multidimensional scaling (Cosine-MDS).

## Overview

The analyses include:

- Construction of Cosine-MDS representations from Harmony-corrected embeddings
- Comparison of developmental transcriptomic landscapes across stages
- Structural similarity analysis using SSIM
- Reference-capped composition matching
- Population-wise exclusion analyses
- Optimal transport analysis
- Slingshot pseudotime and tradeSeq analyses
- Intra-annotation pseudobulk cosine dissimilarity analysis
- Inter-annotation pseudobulk relationship analysis
- Weighted regression and correlation analyses across developmental stages
- Robustness analyses across parameter settings
